# ⏳ Heroes World Online - Página de Pré-Lançamento (Clone)

Recriação da página oficial de contagem regressiva e pré-lançamento do MMORPG **Heroes World Online**, desenvolvida com foco em prática de desenvolvimento front-end puro.

> **Aviso:** Este é um projeto estritamente educacional e sem fins lucrativos, criado apenas para fins de estudo e portfólio. Todos os direitos de marca, imagens e conceitos pertencem aos criadores originais de *Heroes World Online*.

## ✨ Funcionalidades Recriadas
* **Contador Regressivo (Countdown):** Cronômetro em tempo real calculando dias, horas, minutos e segundos para o lançamento oficial.
* **Showcase de Vocações:** Alternância dinâmica entre as 5 classes do jogo (Místico, Druida, Arqueiro, Guerreiro e Ladino) exibindo atributos e descrições.
* **FAQ Interativo:** Seção de perguntas frequentes com abertura e fechamento em formato acordeão.

## 🚀 Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página de pré-lançamento.
* **CSS3:** Estilização temática, layout responsivo e efeitos visuais.
* **JavaScript (Vanilla):** Manipulação de datas para o contador regressivo e interatividade do DOM.
